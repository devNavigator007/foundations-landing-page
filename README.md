# foundations-landing-page

## Roamly - Travel Landing Page

The page is named under the heading "**Roamly**". **Roamly** is a travel-inspired website concept designed to showcase beautiful destinations, inspire travellers and encourage them to plan their next adventure particularly promoting Uttarakhand tourism.


### Overview
The project was built as part of my journey into frontend web development and my practice with HTML, CSS and responsive layouts.

### Features
* Navigation - Simple navigation with brand identity and section links.
* Hero Section - An introductory section with a headline, supporting text, call-to-action button and travel media.
* Destination Gallery - Highlights four travel destinations in Uttarakhand:
  - Kedarnath
  - Rishikesh, Dehradun & Mussoorie
  - Nainital
  - Chopta
* Testimonial Section - A dedicated space for travel inspiration and customer feedback.
* Call-to-Action Section - Encourages visitors to start planning their next adventure.
* Footer - Simple branding and copyright information.

### Built With
* HTML5 - Semantic page structure and content.
* CSS3 - Styling, Flexbox layouts, spacing, typography, and responsice design.
* Google Fonts (Roboto) - Typography.
